05 —— CLARITY

Frequently Asked Questions

Technical details on hardware requirements, CoreML acceleration, and permissions.

Is an internet connection required to use Openflow? +

No. Openflow runs 100% locally on your Mac using WhisperKit CoreML and native Apple Speech models. You can dictate seamlessly in airplane mode or in high-security, air-gapped environments without any network access.

Which Apple Silicon chips and macOS versions are supported? +

Openflow supports all Apple Silicon Macs (M1, M2, M3, M4 and their Pro, Max, and Ultra variants) running macOS 14.0 (Sonoma) or macOS 15.0+ (Sequoia). Both unified memory architectures and Apple Neural Engine acceleration are fully utilized.

How does Openflow paste text directly into any application? +

Openflow uses native macOS Accessibility APIs (`CGEvent` synthesis) to paste formatted transcripts directly into the currently focused text cursor—whether you're writing in VS Code, Cursor, Slack, Obsidian, Chrome, Microsoft Word, or Apple Notes.

What is Kokoro-82M TTS and how does document narration work? +

Kokoro-82M is an ultralightweight, state-of-the-art text-to-speech model converted to CoreML. Openflow uses it to narrate documents, PDFs, and clipboard text with studio-grade natural cadence entirely on the Apple Neural Engine, complete with continuous paragraph flow and sentence scrubbing.

Can I reclaim unified RAM when not dictating? +

Yes. Openflow includes a one-click manual RAM Offload button in settings, as well as an automatic idle release option that unloads neural weights from unified memory when you aren't dictating, returning the memory footprint to near-zero.
