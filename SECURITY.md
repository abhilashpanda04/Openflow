# Security Policy

If you discover a security issue, please do not open a public issue with exploit details.

## Reporting

- Share a private report with clear reproduction steps, impact, and affected version.
- Include logs and traces only after removing tokens, credentials, and personal data.

## Scope

Security-sensitive areas include:

- macOS permissions handling (Microphone, Accessibility)
- backend process launch and environment handling
- transcript transport/authentication (`X-API-Token`)
- local storage of settings and secrets
